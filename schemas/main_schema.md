# Обоснование выбора хранилищ:
PostgreSQL (мастер для всех) – единственный источник истины. Все операции INSERT/UPDATE/DELETE идут первично в PostgreSQL, остальные хранилища обновляются асинхронно через CDC (Change Data Capture) или фоновые задачи.

Redis (кэш высоконагруженных чтений) – список студентов частый запрос.

Neo4j (графовые связи) – иерархии Группы → Посещения Студенты → Посещения представляется в виде графа, а Neo4j особенно эффективен для графовых связей.

MongoDB (документная модель) – хранение документа университет → институт → кафедра в виде json объекта.

ElasticSearch (поиск и анализ) – полнотекстовый и быстрый поиск по текстам лекций и аннотациям.
