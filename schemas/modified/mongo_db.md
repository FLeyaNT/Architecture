# Структура коллекции MongoDB

MongoDB 7 хранит оргструктуру университета одним документом:
университет со вложенными институтами, институты со вложенными кафедрами.

- база: `university_db`
- коллекция: `university_hierarchy`
- документ: один на университет (сейчас 1)
